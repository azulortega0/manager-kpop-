¿Que es HTML?

HTML, que significa HyperText Markup Language, es el lenguaje utilizado para estructurar el contenido web. Permite organizar texto, imagenes, enlaces y más en un documento legible por los navegadores.

Estructura basica de HTML

Un documento HTML se compone de varias etiquetas clave como
< html >,< head > y < body >
La etiqueta < html > envuelve todo el contenido del documento, mientras que < head > contiene informacion sobre el documento, como su titulo.
La etiqueta < body > incluye todo el contenido visible de la pagina.

¿Para que sirve : Lang="es"?

Indica que el contenido de la página web o de un elemento específico está en español. Esto ayuda a los navegadores, motores de búsqueda y lectores de pantalla a entender el idioma del contenido, mejorando la accesibilidad, la traducción y el posicionamiento en buscadores.

¿Para que sirve : < code > < /code >?

Se utiliza para representar código de computadora en un documento web. Al encerrar texto dentro de esta etiqueta, se indica que ese texto debe ser tratado como código y no como texto normal, por lo que se mostrará en una fuente monoespaciada y sin interpretación de etiquetas HTML.

¿Para que sirve : < >?

Son entidades de carácter que se utilizan para representar los símbolos < (menor que) y > (mayor que), respectivamente. Estas entidades son necesarias porque los símbolos < y > tienen significados especiales en HTML (marcan el inicio y el fin de las etiquetas) y no pueden ser utilizados directamente para mostrar esos símbolos en el texto de la página web.

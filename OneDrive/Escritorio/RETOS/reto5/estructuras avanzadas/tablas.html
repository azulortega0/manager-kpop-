ESTRUCTURA BÁSICA DE UNA TABLA.

Una tabla en HTML es una manera organizada de presentar datos en un formato tabular. La estructura básica de una tabla se compone de varios elementos que trabajan juntos para definir cómo se muestra la información.

Elemento < table > :Este es el contenedor principal que agrupa todos los componentes de la tabla. Dentro de este elemento, se colocan las filas y celdas.

Filas < tr > :Cada fila de la tabla se define con el elemento (table row). Este elemento puede contener celdas de encabezado o celdas de datos.

Celdas de Encabezado < th > :Dentro de las filas, se pueden incluir celdas de encabezado utilizando el elemento (table header). Estas celdas suelen aparecer en la primera fila y están diseñadas para describir el contenido de cada columna. Por defecto, el texto en aparece en negrita y centrado.

Celdas de Datos < td> :Las celdas de datos, definidas con el elemento (table data), contienen la información específica que se presenta en la tabla. Estas celdas pueden incluir texto, imágenes, enlaces y otros tipos de contenido.


ESTILIZACIÓN

Para mejorar la apariencia de las tablas, se pueden aplicar estilos CSS. Por ejemplo, se pueden agregar bordes, colores de fondo y espaciado interno para hacer la tabla más legible y atractiva.

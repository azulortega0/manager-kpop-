Listas Ordenadas

Las listas ordenadas se utilizan para agrupar elementos que deben seguir un orden específico. Se representan con el elemento < ol> (ordered list), y al igual que en las listas desordenadas, cada elemento se define con < li >. Por defecto, los elementos en una lista ordenada se numeran.

Las listas ordenadas se utilizan cuando el orden de los elementos es importante. Cada elemento de la lista se numera automáticamente.

Ejemplo De Uso:

            
    
                
  1. 1. Primer elemento.
    2. 
                
  2. 2. Segundo elemento.
    3. 
                
  3. 3. Tercer elemento.
    4.

CODIGO:

< ol >

< li > Primer elemento

< li > Primer elemento

< li > Primer elemento

< /ol >

Lista NO Ordenada

Las listas desordenadas se utilizan para agrupar elementos que no requieren un orden específico. Se representan con el elemento < ul > (unordered list) y cada elemento de la lista se define con < li > (list item). Por defecto, los elementos en una lista desordenada se muestran con viñetas.

Las listas no ordenadas se utilizan cuando el orden no es relevante. Cada elemento de la lista se presenta con un viñeta.

Ejemplo de Uso:

            
    
                
  • Elemento A
    • 
                
  • Elemento B
    • 
                
  • Elemento C
    •

CODIGO:

< ol >

< li> Primer elemento < /li >

< li >Segundo elemento < /li >

< li >Tercer elemento < /li >

< /ol >
